# Reze Website

Static site (GitHub Pages). Upload the whole folder keeping names:

- `index.html` – the whole app (HTML, CSS, JS)
- `Reze_Hoa.mp4`, `Reze_Yen_Binh.mp4` – background / hero videos
- `data/manifest.json` + `data/media|cover|thumb/` – published library (referenced by the manifest)

Library data otherwise lives in the browser (IndexedDB); use Sao lưu / Khôi phục to move it between devices.
