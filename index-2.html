Xuất bản thư viện

Đưa ảnh, video, nhạc và văn bản lên web để bất kỳ ai mở link cũng thấy, không chỉ nằm trong trình duyệt của một máy.

Đang kiểm tra bản công khai…

Chế độ chủ web — xuất bản (cần token GitHub)

Điền token rồi bấm Xuất bản. Mọi file sẽ được đưa vào thư mục data/ của repo.

Cách lấy token (1 lần)
  1. Vào GitHub → ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → chọn repo của website này.
  3. Permissions → Repository permissions → Contents: Read and write. Bấm Generate rồi sao chép token vào ô trên.

Token cho phép sửa repo, hãy giữ kín và không gửi cho ai. Token chỉ nằm trong trình duyệt này, không nằm trong file sao lưu và không được đưa lên web. Lưu ý: ảnh/video đã xuất bản là công khai — ai biết đường dẫn trong thư mục data/ đều xem được, mật khẩu mở trang chỉ che giao diện.
